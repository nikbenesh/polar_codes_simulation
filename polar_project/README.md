# Моделирование полярных кодов с SCL-декодированием в канале AWGN

Данный проект реализует численное моделирование полярных кодов с последовательным списочным декодированием (SCL) в канале AWGN с BPSK-модуляцией.  
Проект используется для исследования зависимости FER (Frame Error Rate) от Eb/N0 при различных параметрах кода и декодера.

Реализованы:
- построение полярного кода;
- выбор информационных позиций двумя способами:
  - по Gaussian Approximation (GA);
  - по NR-упорядочиванию (rank.csv);
- SC- и SCL-декодирование;
- поддержка CRC;
- построение графиков FER(Eb/N0);
- интерактивный веб-интерфейс (Streamlit).

## Основные файлы и их назначение

### `runner.py`
Главный вычислительный модуль.

Функция:
```python
run_one_case(...)
````

выполняет:

1. построение полярного кода;
2. передачу кодового слова через AWGN-канал;
3. декодирование (SC / SCL);
4. подсчёт FER;
5. сохранение:

   * CSV-файла с результатами;
   * PNG-графика FER(Eb/N0).

Поддерживает:

* `yield_mode=True` — для поэтапного обновления интерфейса;
* `use_nr_sequence=True` — использование `rank.csv`;
* CRC при SCL-декодировании.

---

### `polar.py`

Содержит реализацию:

* полярного преобразования (Arıkan);
* выбора frozen-битов:

  * по Gaussian Approximation;
  * по NR-таблице (rank.csv).

Именно здесь определяется, какие битовые позиции являются информационными.

---

### `scl.py`

Реализация:

* SC-декодера;
* SCL-декодера (наивная, но корректная реализация);
* метрики пути;
* поддержки CRC (выбор корректного пути из списка).

---

### `awgn.py`

Модель канала:

* BPSK-модуляция;
* аддитивный белый гауссов шум (AWGN);
* переход от Eb/N0 к дисперсии шума.

---

### `crc.py`

Реализация CRC:

* добавление CRC к информационным битам;
* проверка CRC при декодировании.

CRC используется для выбора корректного пути в SCL-декодере и существенно улучшает FER.

---

### `rank.csv`

Таблица надёжности битовых каналов, используемая в стандартах 5G NR.

Содержит два столбца:

* `W` — номер позиции;
* `Q` — её относительная надёжность.

Используется для определения информационных позиций вместо GA, что ускоряет работу и приближает модель к стандартам связи.

# Запуск программы

!!! Во всех случаях проект нужно запускать не из папки polar_project, а из папки, которая находится над ней и в которой также лежит rank.csv и app.py !!! 

## Запуск программы без интерфейса (batch-режим) 

### 1. Запуск одного кейса (быстрый тест)

```bash
python -m polar_project.runner
```

Запускается демонстрационный расчёт с небольшим числом кадров.

---

### 2. Запуск всех кейсов из задания

```bash
python -m polar_project.run_cases
```

* Запускается без аргументов.
* Все параметры заданы в коде согласно заданию.
* После каждого кейса:

  * сохраняется CSV;
  * сохраняется PNG-график.
* Результаты сохраняются в папку `results_nr_crc/`.
Время выполнения ~1 час 

---

## Запуск веб-интерфейса (Streamlit)

### 1. Установка зависимостей

```bash
pip install numpy matplotlib pandas streamlit
```

---

### 2. Запуск интерфейса

Из корня проекта (т е из папки над polar project):

```bash
streamlit run app.py
```

После этого в браузере откроется интерфейс.

## Возможности интерфейса

В интерфейсе можно:

* задать:

  * длину кода `n`;
  * скорость `R`;
  * размер списка `L`;
  * диапазон Eb/N0;
* выбрать способ построения кода:

  * Gaussian Approximation;
  * NR sequence (rank.csv);
* включить или выключить CRC;
* наблюдать:

  * обновление графика FER в реальном времени;
  * численные значения ошибок.

## Теоретические замечания

* В качестве модуляции используется BPSK.
* Канал — AWGN.
* По оси X графиков используется Eb/N0, так как эта величина корректно сравнивает системы с разной кодовой скоростью.
* Использование:

  * SCL + CRC даёт наилучшие результаты;
  * NR-упорядочивание может давать менее гладкие кривые FER при малых длинах кодов, что является ожидаемым эффектом.

---

## Примечания

* Реализация SCL-декодера является наивной, ориентированной на корректность, а не на скорость.
* При больших `n` и `L` расчёты могут занимать значительное время.
* Для демонстрации рекомендуется начинать с `n = 128`.
